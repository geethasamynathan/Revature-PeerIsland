# LangChain Advanced with Gemini -- Real-World HR Policy Assistant

## Covers

-   Memory
-   Conversation management
-   RAG
-   Document loaders
-   Text splitters
-   Embeddings
-   Vector stores
-   Gemini API integration

## Workflow

1.  Load documents
2.  Split into chunks
3.  Create embeddings
4.  Store in FAISS
5.  Retrieve relevant chunks
6.  Add memory history
7.  Send to Gemini
8.  Return grounded answer
