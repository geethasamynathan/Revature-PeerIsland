# Prompt Engineering 

## Introduction

**Prompt Engineering** is the **art and science of writing clear
instructions for AI models so they give the best possible output.**

Think of it like talking to a highly intelligent assistant:

-   If your instruction is **clear, specific, and structured**, the
    answer is **excellent** ✅
-   If your instruction is **vague or confusing**, the answer may be
    **poor** ❌

Today, prompt engineering is widely used in:

-   AI chatbots
-   Coding assistants
-   Content generation
-   Image generation
-   Training bots
-   Automation
-   Customer support
-   Education
-   Data analysis

------------------------------------------------------------------------

## 1) Simple Definition

### Prompt = Instruction given to AI

**Example:**

``` text
Write a Python program to sort numbers.
```

This is a **prompt**.

### Prompt Engineering = Designing better prompts

**Example:**

``` text
Write a Python program using bubble sort to sort integer numbers in ascending order with step-by-step comments.
```

This is **prompt engineering** because it improves clarity.

## 3) Core Formula of a Good Prompt

A strong prompt usually has the following components:

### A) Role

Tell AI who it should act as.

**Example:**

``` text
Act as a senior Java full stack architect.
```

### B) Task

What exactly should it do?

**Example:**

``` text
Build a login module.
```

### C) Context

Provide the **project or business use case**.

**Example:**

``` text
For an e-commerce application.
```

### D) Constraints

Mention **rules, limits, technologies, or standards**.

**Example:**

``` text
Use Spring Boot, React, MySQL, JWT.
```

### E) Output Format

Specify the **expected response structure**.

**Example:**

``` text
Give code with folder structure and explanation.
```

------------------------------------------------------------------------

## Final Prompt Formula (Easy Template)

``` text
Act as [Role]
Perform [Task]
For [Context]
Using [Constraints]
Output in [Format]
```

### Real Example

``` text
Act as a senior Java full stack architect.
Build a secure login module.
For an e-commerce application.
Use Spring Boot, React, MySQL, JWT.
Give code with folder structure and explanation.
```

------------------------------------------------------------------------

## Best Practice Tips

To write better prompts:

-   Be specific
-   Mention technologies clearly
-   Ask for examples
-   Ask for step-by-step explanation
-   Define output format
-   Mention beginner/intermediate/advanced level
-   Add real-world use case
-   Mention coding standards if needed

------------------------------------------------------------------------

## Bad vs Good Example

### ❌ Bad Prompt

``` text
Create login code.
```

### ✅ Good Prompt

``` text
Act as a senior full stack developer.
Create a login module for an e-commerce app using Spring Boot, React, MySQL, and JWT authentication.
Provide backend APIs, React UI, database schema, and folder structure with explanation.
```
