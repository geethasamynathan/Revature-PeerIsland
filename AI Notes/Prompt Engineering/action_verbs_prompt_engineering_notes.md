# 📘 Action Verbs to Create Better Prompts

**Action verbs** are the **instruction words** that tell AI *what
exactly to do*.

They are the **heart of prompt engineering** because they define the
task.

Instead of writing vague prompts, use strong action verbs.

------------------------------------------------------------------------

## ✅ Common Action Verbs for Prompt Writing

### 📝 Content Creation

Use when you want AI to generate content.

-   **Write** → Write a blog on AI
-   **Create** → Create a lesson plan
-   **Generate** → Generate 10 interview questions
-   **Draft** → Draft an email to HR
-   **Compose** → Compose a professional LinkedIn post
-   **Develop** → Develop a product roadmap

### 💻 Coding / Technical

Use for programming prompts.

-   **Build** → Build a REST API in Java
-   **Implement** → Implement JWT authentication
-   **Debug** → Debug this Python code
-   **Optimize** → Optimize SQL query performance
-   **Refactor** → Refactor this React component
-   **Explain** → Explain microservices architecture
-   **Compare** → Compare .NET vs Java Spring Boot

### 📚 Learning / Teaching

Best for training, notes, and explanations.

-   **Explain**
-   **Teach**
-   **Summarize**
-   **Describe**
-   **List**
-   **Outline**
-   **Break down**
-   **Illustrate**

**Example:**\
**Explain** prompt engineering with real-world examples.

### 📊 Analysis / Data

For logical and business prompts.

-   **Analyze**
-   **Evaluate**
-   **Assess**
-   **Predict**
-   **Classify**
-   **Interpret**
-   **Calculate**
-   **Identify**

**Example:**\
**Analyze** customer churn data and suggest retention strategies.

### 🎨 Creative

Useful for branding, stories, and ideas.

-   **Design**
-   **Imagine**
-   **Brainstorm**
-   **Invent**
-   **Suggest**
-   **Recommend**
-   **Rewrite**
-   **Transform**

**Example:**\
**Brainstorm** 20 startup ideas using AI.

------------------------------------------------------------------------

## ✅ Why Action Verbs Matter

### ❌ Without action verb

> AI project management

### ✅ With action verb

> **Create** a project management plan for AI implementation

Second prompt gives: - Clear task - Better structure - Faster response -
Less confusion

------------------------------------------------------------------------

## ✅ Best Prompt Formula Using Action Verbs

**Action Verb + Task + Context + Format + Constraints**

### Example

> **Create** a Python Flask API for employee management with CRUD
> operations, MySQL integration, and JWT authentication. Provide folder
> structure and explanation.

-   **Create** = Action verb
-   **Python Flask API** = Task
-   **Employee management** = Context
-   **Folder structure** = Format
-   **JWT + MySQL** = Constraints
